# `(srfi s8 receive)` — SRFI-8 receive

```scheme
(import (srfi s8 receive))
```

[SRFI-8](https://srfi.schemers.org/srfi-8/): a single macro for binding multiple return values without the `call-with-values`/`lambda` boilerplate.

#### `(receive formals expression body ...)` — *syntax*

Evaluates `expression` (which should return zero or more values, e.g. via `values`), binds them to `formals`, then evaluates `body ...` in that scope, returning its value(s). `formals` follows the same three shapes as a `lambda` parameter list:

```scheme
;; fixed arity
(receive (q r) (floor/ 7 2) (list q r))          ; => (3 1)

;; rest arg — all values after the first collected into a list
(receive (first . rest) (values 1 2 3) rest)      ; => (2 3)

;; single variadic binding — every value collected into a list
(receive all (values 1 2 3) all)                  ; => (1 2 3)
```

Equivalent, by definition, to `(call-with-values (lambda () expression) (lambda formals body ...))`.

**Importing this shadows curry's own `receive` special form** (actor mailbox receive — `spawn`/`send!`/`receive`, see `src/actors.c`) for the rest of the importing program's top level. The two are unrelated: SRFI-8's `receive` destructures multiple return values from an ordinary expression; curry's own `receive` blocks the calling actor until a message arrives in its mailbox. Don't import this library into code that also uses actor mailboxes — pick whichever name you need and, if you need both in one program, call the actor form via a different name (or use `call-with-values` directly instead of importing this).
