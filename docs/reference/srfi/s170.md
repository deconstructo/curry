# `(srfi s170 posix)` — SRFI-170 POSIX API (subset)

```scheme
(import (srfi s170 posix))
```

Thin re-export of `(curry posix)` under the portable [SRFI-170](https://srfi.schemers.org/srfi-170/) name — see [`../module-posix.md`](../module-posix.md) for the full procedure list and the C module's scope (what's implemented vs. deliberately left out for a first pass: `posix-error?` introspection, `open-file`/`fd->port`, `create-fifo`, temp-file helpers, `file-space`, and the directory-generator API). Requires curry built with `-DBUILD_MODULE_POSIX=ON` (the default) — unlike most other `srfi` libraries, this one can't be pure Scheme, since `stat`, `opendir`/`readdir`, `getuid`, `chmod`, `symlink`, `umask`, and `getpid` have no Scheme-level equivalent to build on.
