# `(srfi s145 assume)` — SRFI-145 assume

```scheme
(import (srfi s145 assume))
```

[SRFI-145](https://srfi.schemers.org/srfi-145/): declares a runtime invariant. The SRFI permits a conforming implementation to elide the check entirely in "production" builds (trusting the invariant rather than testing it, for speed); curry always checks it and raises on violation, since there's no separate production-mode build flag to key elision on — `assume` behaves exactly like a plain `if`-and-`error` here, every time.

#### `(assume expr)` — *syntax*
#### `(assume expr message ...)` — *syntax*

If `expr` evaluates to `#f`, raises an `error-object` whose message is `"assumption violated"` and whose irritants are `expr`'s *source form* (not its value, so the error is legible even when `expr` involves variables that have since changed) followed by the evaluated `message ...` arguments, in order. Otherwise returns unspecified. `expr` and each `message` are evaluated at most once.

```scheme
(define (deposit! acct amount)
  (assume (> amount 0) "deposit amount must be positive:" amount)
  (set-balance! acct (+ (balance acct) amount)))

(guard (e (#t (error-object-irritants e)))
  (deposit! acct -5))
; => ((> amount 0) "deposit amount must be positive:" -5)
```

#### `(assume-type obj pred . message)` → *obj*

If `(pred obj)` is false, raises an `error-object` whose message is `"assumption violated: wrong type"` and whose irritants are `obj` followed by any `message` arguments; otherwise returns `obj` unchanged, so it composes inline in an expression rather than needing its own statement.

```scheme
(define (half n)
  (/ (assume-type n integer? "half: expected an integer") 2))

(half 4)      ; => 2
(guard (e (#t (error-object-irritants e))) (half "x"))
; => ("x" "half: expected an integer")
```

Unrelated to curry's own `assume!`/`can-assume?` (`src/builtins_curry.c`), which record algebraic assumptions (e.g. "`x` is positive") on symbolic CAS variables for the simplifier to use — those are compile-time-ish facts about a symbol, not runtime boolean checks on a concrete value.
