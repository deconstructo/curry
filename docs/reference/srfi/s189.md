# `(srfi s189 maybe-either)` — SRFI-189

```scheme
(import (srfi s189 maybe-either))   ; or (srfi 189), or (srfi srfi-189)
```

[SRFI-189](https://srfi.schemers.org/srfi-189/) Maybe and Either: two immutable optional-value container-type families. A **Maybe** is a `Just` (success, holding zero or more payload values) or the unique `Nothing`. An **Either** is a `Right` (success, zero or more values) or a `Left` (failure, zero or more values). Both payloads are genuinely variadic — a `(just)` with no values is a real, distinct success value, not the same as `(nothing)`.

```scheme
(define (safe-div a b) (if (zero? b) (nothing) (just (/ a b))))
(maybe-ref (safe-div 10 2) (lambda () 'div-by-zero))   ; => 5
(maybe-ref (safe-div 10 0) (lambda () 'div-by-zero))   ; => div-by-zero
```

## Types and predicates

`(just obj ...)`, `(nothing)`, `(right obj ...)`, `(left obj ...)` — constructors. `(just? obj)`, `(nothing? obj)`, `(right? obj)`, `(left? obj)`, `(maybe? obj)` (Just or Nothing), `(either? obj)` (Right or Left). `(list->just lst)`/`(list->left lst)`/`(list->right lst)` treat `lst`'s own elements as the payload directly (not "a payload of one value, the list").

## Comparing

#### `(maybe= equal maybe1 maybe2 ...)` / `(either= equal either1 either2 ...)`

`#t` if every argument has the same "shape" (all Nothing, or all Just/Right/Left with `equal`-equal payloads element-by-element).

## Converting between Maybe and Either

`(maybe->either maybe obj ...)` — Just → Right (same payload); Nothing → Left of `obj ...`. `(either->maybe either)` — Right → Just (same payload); Left → Nothing (payload dropped). `(either-swap either)` — Right ↔ Left, same payload.

## Accessors

#### `(maybe-ref maybe failure [success])`

Just calls `(success . payload)` (default `success`: `values`) and returns the result; Nothing calls `(failure)` (no arguments).

#### `(either-ref either failure [success])`

Right calls `(success . payload)`; **Left calls `(failure . payload)`** — the Left's own payload, not a zero-arg call. This asymmetry with `maybe-ref` is the spec's own design, not an inconsistency here.

#### `(maybe-ref/default maybe default ...)` / `(either-ref/default either default ...)`

Payload values if Just/Right, otherwise the given defaults, as multiple values.

## Monadic operations

`(maybe-join maybe)` / `(either-join either)` — unwraps a Just/Right of exactly one Maybe/Either value; raises otherwise (multiple or zero payload values, or a payload that isn't itself a Maybe/Either).

`(maybe-compose mproc ...)` / `(either-compose mproc ...)` — returns a new function chaining monadic functions (each mapping plain values to a Maybe/Either), short-circuiting the first time one returns Nothing/Left.

`(maybe-bind maybe mproc ...)` / `(either-bind either mproc ...)` — unwraps `maybe`/`either` and threads it through the composed chain; Nothing/Left passes through unchanged without calling anything.

## Sequence-flavored operations

`(maybe-length maybe)` / `(either-length either)` → `1` or `0`, regardless of the payload's own value count — this treats the container itself as a 0-or-1-element sequence.

`(maybe-filter pred maybe)` / `(maybe-remove pred maybe)` — keep `maybe` if `(pred . payload)` is true/false respectively, else `(nothing)`. `(either-filter pred either obj ...)` / `(either-remove pred either obj ...)` — same idea, but the "otherwise" case is `(apply left objs)`, not the original Either unchanged (matches the spec's own literal wording).

#### `(maybe-sequence mappable map [aggregator])` / `(either-sequence mappable map [aggregator])`

Transforms a collection of Maybes/Eithers into a Maybe/Either of a collection. `map`'s own signature is `(map proc mappable)` (pass ordinary `map` for a list `mappable`). Each element's unwrapped payload is passed to `aggregator` (default `list`) — since `aggregator` always receives the payload as separate arguments, a **single-valued** payload becomes a one-element list per slot with the default aggregator:

```scheme
(maybe-sequence (list (just 1) (just 2)) map)              ; => (just '((1) (2)))
(maybe-sequence (list (just 1) (just 2)) map (lambda (x) x)) ; => (just '(1 2))
(maybe-sequence (list (just 1) (nothing)) map)              ; => (nothing)  -- short-circuits
```

This implementation's own note: correctness of the "find the first failure" pass is guaranteed for a list `mappable` with the ordinary list `map` (the common case, and the only shape this library's own test suite exercises); a `mappable`/`map` pair producing some other collection shape (e.g. `vector-map`) isn't specifically supported by that second pass.

## Protocol conversions

Six protocols, each translating between a Maybe/Either and a different plain-Scheme "how do I spell success/failure" convention:

| Protocol | Failure spelled as | Success spelled as |
|---|---|---|
| list | `'()` | a list of the payload values |
| truth | `#f` | the single payload value |
| list-truth | `#f` | a list of the payload values |
| generation | the eof-object | the single payload value |
| values | zero returned values | the payload as multiple values |
| two-values | `(values #f #f)` | `(values v #t)` |

Each has four procedures: `maybe->X`, `either->X`, `X->maybe`, `X->either` (e.g. `maybe->list`, `either->list`, `list->maybe`, `list->either`) — except two-values, which is Maybe-only (`maybe->two-values`, `two-values->maybe`).

#### `(exception->either pred thunk)`

Runs `thunk`. If it returns normally (possibly with multiple values), wraps the result in a `Right`. If it raises a condition satisfying `pred`, wraps the condition in a `Left`. If it raises a condition `pred` doesn't match, re-raises.

## Map, for-each, fold, unfold

`(maybe-map proc maybe)` / `(either-map proc either)`, `(maybe-for-each proc maybe)` / `(either-for-each proc either)` (no-op on Nothing/Left), `(maybe-fold kons nil maybe)` / `(either-fold kons nil either)` (returns `nil` unchanged for Nothing/Left).

#### `(maybe-unfold stop? mapper successor seed ...)` / `(either-unfold stop? mapper successor seed ...)`

An unusually narrow procedure — genuinely not a general recursive loop, matching the spec's own text taken literally: `stop?` is called **at most twice**. If `(stop? . seed...)` is true immediately, returns `(nothing)`/`(left seed...)`. Otherwise `successor` computes new seeds; if `stop?` is *still* false on those, it's an error (this procedure only ever takes one step). If `stop?` is now true, `mapper` is applied to the new seeds and the result wrapped in `Just`/`Right`.

```scheme
(maybe-unfold (lambda (n) (= n 1)) (lambda (n) (* n 100)) (lambda (n) 1) 0)
; => (just 100)   -- stop? false on 0, successor always returns 1, stop? true on 1, mapper(1) = 100
```

## Syntax

`(maybe-if maybe-expr just-expr nothing-expr)` — raises (an `error-object?`-satisfying condition) if `maybe-expr` isn't a Maybe. `(maybe-and expr ...)` / `(either-and expr ...)` — short-circuit on Nothing/Left, else the last expression's value. `(maybe-or expr ...)` / `(either-or expr ...)` — short-circuit on the first Just/Right, else the last (a Nothing/Left).

#### `(maybe-let* (claw ...) body ...)` / `(either-let* (claw ...) body ...)`

Each *claw* is a bound identifier, `(expr)`, or `(var expr)` — evaluating `expr` (or referencing the identifier) must produce a Maybe/Either whose payload is **exactly one value**; a claw with zero or multiple payload values raises. Short-circuits to the first Nothing/Left hit.

#### `(maybe-let*-values (claw ...) body ...)` / `(either-let*-values (claw ...) body ...)`

Same claw shapes, but a `(var expr)` claw's `var` may also be a formals list (mirroring R7RS `let-values`), binding *every* payload value via `apply` rather than requiring exactly one.

#### `(either-guard pred-expr body ...)`

`(exception->either pred-expr (lambda () body ...))` — note the shape difference from ordinary `guard`: no variable-binding clause, just a predicate expression tested against whatever's raised.

## Trivalent logic

A `Maybe` wrapping a single boolean, used as a three-valued (true/false/unknown) logic value.

`(tri-not maybe)`, `(tri=? maybe ...)` (`Just #t` iff all arguments share the same nothingness/value), `(tri-and maybe ...)` (first `Nothing`/`Just #f` encountered, else `Just #t`), `(tri-or maybe ...)` (first `Nothing`/`Just #t` encountered, else `Just #f`), `(tri-merge maybe ...)` (the first `Just` regardless of its value, else `Nothing`).
