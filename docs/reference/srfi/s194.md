# `(srfi s194 random-data-samples)` — SRFI-194

```scheme
(import (srfi s194 random-data-samples))
```

[SRFI-194](https://srfi.schemers.org/srfi-194/) generators follow [`(srfi s158)`](s158.md)'s thunk protocol directly — call repeatedly, get an endless stream of samples (these never exhaust; there's no eof-object case). `make-zipf-generator` and the geometry samplers (sphere/ball/rectangle) from the full SRFI are out of scope.

Continuous distributions (`make-uniform-generator`, `make-normal-generator`, `make-exponential-generator`) delegate to `(curry random)`'s samplers. Discrete ones (bernoulli/binomial/geometric/poisson/categorical) are implemented directly here, since `(curry random)` intentionally omits discrete distributions in favor of `T_QUANTUM`.

#### `(make-random-integer-generator lo hi)` → *generator of exact integers in `[lo, hi)`*
#### `(make-random-real-generator lo hi)` → *generator of flonums in `[lo, hi)`*
#### `(make-random-boolean-generator)` → *generator, `#t` with probability 0.5*
#### `(make-random-boolean-generator p)` → *generator, `#t` with probability `p`*
#### `(make-random-char-generator str)` → *generator, uniformly picks one character of `str` each call*

```scheme
((make-random-integer-generator 0 10))  ; => an exact integer in 0..9
```

#### `(make-uniform-generator lo hi)` → *generator of flonums, uniform on `[lo, hi)`*
#### `(make-normal-generator)` → *generator, standard normal (mean 0, stddev 1)*
#### `(make-normal-generator mean)` → *generator, normal(mean, 1)*
#### `(make-normal-generator mean stddev)` → *generator, normal(mean, stddev)*
#### `(make-exponential-generator)` → *generator, exponential with rate 1.0*
#### `(make-exponential-generator rate)` → *generator, exponential(rate)*

#### `(make-bernoulli-generator)` → *generator, `#t`/`#f` with `p`=0.5*
#### `(make-bernoulli-generator p)` → *generator, `#t` with probability `p`, `#f` otherwise*

Same distribution as `make-random-boolean-generator`; provided under both names for spec compatibility.

#### `(make-binomial-generator n)` → *generator of exact integers, `Binomial(n, 0.5)`*
#### `(make-binomial-generator n p)` → *generator of exact integers, `Binomial(n, p)`*

Number of successes out of `n` independent trials, each succeeding with probability `p`.

#### `(make-geometric-generator)` → *generator of exact integers ≥ 1, `Geometric(0.5)`*
#### `(make-geometric-generator p)` → *generator of exact integers ≥ 1, `Geometric(p)`*

Number of trials (including the successful one) up to and including the first success, each trial succeeding with probability `p`.

#### `(make-poisson-generator mu)` → *generator of exact integers ≥ 0, `Poisson(mu)`*

Knuth's algorithm (multiply uniform draws until the running product drops below `e^-mu`).

#### `(make-categorical-generator weights)` → *generator*

`weights` is a list of `(value . weight)` pairs with positive weights (need not sum to 1 — normalized internally). Each call returns one `value`, chosen with probability proportional to its weight.

```scheme
((make-categorical-generator (list (cons 'a 1) (cons 'b 9))))
; => 'a about 10% of the time, 'b about 90%
```
