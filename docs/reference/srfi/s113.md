# `(srfi s113 sets-and-bags)` — SRFI-113 sets and bags

```scheme
(import (srfi s128 comparators) (srfi s113 sets-and-bags))
```

[SRFI-113](https://srfi.schemers.org/srfi-113/). Sets are a comparator-adapter wrapper over curry's native set (`src/set.h`) — bucketed under eq?/eqv?/equal? exactly like [`(srfi s125 hash-tables)`](s125-s126.md), and reusing several native primitive *names* (`set-union`, `set-copy`, `set=?`, `set-add!`, …) for this library's differently-shaped SRFI-113 API. Bags (multisets) are pure Scheme, built on a comparator-adapted hash table mapping element → count.

`bag-search!` and the full SRFI's mutable/immutable distinction beyond the `!` suffix convention are out of scope.

## Sets

#### `(set comparator elt ...)` → *set*

Create a set containing `elt ...`, bucketed by `comparator`'s equality.

#### `(set? obj)` → *boolean*
#### `(set-comparator s)` → *comparator*
#### `(set-empty? s)` → *boolean*
#### `(set-size s)` → *exact integer*
#### `(set-contains? s x)` → *boolean*
#### `(set-disjoint? s1 s2)` → *boolean*

#### `(set-member s x default)` → *`x` or `default`*

`x` if `s` contains it, `default` otherwise — useful when the set's equality doesn't imply object identity (e.g. two `equal?` but non-`eq?` strings) and you want the *set's own* copy of the element back, though this implementation returns the queried `x` itself either way.

#### `(set-adjoin s elt ...)` → *new set*
#### `(set-adjoin! s elt ...)` → *s*
#### `(set-delete s elt ...)` → *new set*
#### `(set-delete! s elt ...)` → *s*
#### `(set-delete-all s elt-list)` → *new set*
#### `(set-delete-all! s elt-list)` → *s*

Non-`!` versions return a modified copy, leaving `s` untouched; `!` versions mutate `s` in place and return it. `-all` variants take the elements as one list argument instead of variadically.

#### `(set-find pred s failure)` → *element or `(failure)`*
#### `(set-count pred s)` → *exact integer*
#### `(set-any? pred s)` → *boolean*
#### `(set-every? pred s)` → *boolean*

#### `(set-map comparator proc s)` → *new set*

Applies `proc` to every element, collecting results into a *new* set bucketed by `comparator` (which need not match `s`'s own comparator — e.g. mapping a string set through `string-length` needs a numeric comparator for the result).

#### `(set-for-each proc s)`
#### `(set-fold proc knil s)` → *value*

`set-fold` calls `(proc element acc)` for each element, left to right in whatever order the set iterates, threading the accumulator from `knil`. (Note: curry's *native* `set-fold` primitive underneath uses the opposite argument order, `(proc acc element)` — this SRFI-113 wrapper swaps it to match SRFI-1/SRFI-113 convention; don't mix up the two if you also use the native primitive directly.)

#### `(set-filter pred s)` → *new set*
#### `(set-filter! pred s)` → *s*
#### `(set-remove pred s)` → *new set* — keeps elements where `pred` is `#f`
#### `(set-remove! pred s)` → *s*
#### `(set-partition pred s)` → *two values: matching set, non-matching set*

`set-partition` returns two values — use `call-with-values`, not `let-values` (currently unsupported in compiled code, see the top-level project notes).

#### `(set-copy s)` → *new set*
#### `(set->list s)` → *list*
#### `(list->set comparator lst)` → *set*

#### `(set=? s ...)` → *boolean*
#### `(set<? s1 s2)` / `(set<=? s1 s2)` / `(set>? s1 s2)` / `(set>=? s1 s2)` → *boolean*

Set equality and (proper/non-proper) subset ordering. `set=?` is variadic (chained, like `=`); the four relational ones take exactly two sets.

#### `(set-union s1 s2)` / `(set-union! s1 s2)`
#### `(set-intersection s1 s2)` / `(set-intersection! s1 s2)`
#### `(set-difference s1 s2)` / `(set-difference! s1 s2)`
#### `(set-xor s1 s2)` / `(set-xor! s1 s2)` — symmetric difference

Non-`!` returns a new set (using `s1`'s comparator); `!` mutates `s1` in place and returns it. Note `set-xor!` here still allocates a fresh result internally rather than mutating truly in place — it returns a new (correctly re-tagged) set rather than reusing `s1`'s storage, unlike the other `!` variants.

```scheme
(define s (set string-comparator "a" "b" "c"))
(set-size (set-union s (set string-comparator "b" "d")))  ; => 4
```

## Bags (multisets)

#### `(bag comparator elt ...)` → *bag*

Create a bag; repeated `elt`s increment that element's count.

#### `(bag? obj)` → *boolean*
#### `(bag-comparator b)` → *comparator*
#### `(bag-empty? b)` → *boolean*
#### `(bag-contains? b x)` → *boolean*
#### `(bag-element-count b x)` → *exact integer* — `0` if absent
#### `(bag-unique-size b)` → *exact integer* — count of distinct elements
#### `(bag-size b)` → *exact integer* — total count including duplicates

#### `(bag-adjoin b elt ...)` → *new bag*
#### `(bag-adjoin! b elt ...)` → *b*

Increment each `elt`'s count by one (adding it fresh at count 1 if absent).

#### `(bag-delete b elt ...)` → *new bag*
#### `(bag-delete! b elt ...)` → *b*

Decrement each `elt`'s count by one; removed entirely once its count reaches zero. Deleting an absent element is a no-op (not an error).

#### `(bag-copy b)` → *new bag*
#### `(bag->list b)` → *list, with duplicates*
#### `(list->bag comparator lst)` → *bag*
#### `(bag->alist b)` → *alist of `(element . count)`*
#### `(alist->bag comparator alist)` → *bag*

```scheme
(define b (bag string-comparator "a" "a" "b"))
(bag-element-count b "a")  ; => 2
(bag-size b)                ; => 3
(bag->list b)                ; => ("a" "a" "b")   (order unspecified)
```

#### `(bag-for-each proc b)`
#### `(bag-fold proc knil b)` → *value*
#### `(bag-map comparator proc b)` → *new bag*
#### `(bag-filter pred b)` → *new bag*
#### `(bag-any? pred b)` / `(bag-every? pred b)` → *boolean*
#### `(bag-count pred b)` → *exact integer*

All operate over `(bag->list b)` (i.e. each duplicate is visited/counted separately, `pred`/`proc` applied once per occurrence).

#### `(bag-union b1 b2)` / `(bag-union! b1 b2)` — per-element max count
#### `(bag-sum b1 b2)` / `(bag-sum! b1 b2)` — per-element added count
#### `(bag-intersection b1 b2)` — per-element min count (no `!` variant)
#### `(bag-product n b)` / `(bag-product! n b)` — every count scaled by exact integer `n`
#### `(bag=? b1 b2)` → *boolean*

Same non-`!`-returns-new/`!`-mutates-in-place convention as sets.
