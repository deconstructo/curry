# `(srfi s8 receive)` — SRFI-8 receive

```scheme
(import (srfi s8 receive))
(receive (q r) (floor/ 7 2) (list q r)) ; => (3 1)
```

A single macro, per [SRFI-8](https://srfi.schemers.org/srfi-8/): `(receive formals expression body ...)` binds `expression`'s multiple values to `formals` (as `lambda` formals — fixed, rest, or dotted) around `body`.

**Importing this shadows curry's own `receive` special form** (actor mailbox receive — `spawn`/`send!`/`receive`, see `src/actors.c`) for the rest of the importing program's top level; don't import it into code that also uses actor mailboxes.
