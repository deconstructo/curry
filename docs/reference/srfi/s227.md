# `(srfi s227 optional-arguments)` — SRFI-227 optional arguments

```scheme
(import (srfi s227 optional-arguments))
```

[SRFI-227](https://srfi.schemers.org/srfi-227/) optional and rest arguments with defaults, à la MIT/GNU Scheme.

**Spelled `#:optional`/`#:rest`, not the SRFI's `#!optional`/`#!rest`** — curry's reader treats any `#!` as a shebang-style line comment anywhere in the source (not just the first line), so that literal syntax can't be read at all here; `#:keyword` is curry's existing Guile/Racket-style reader syntax and is the closest available substitute.

#### `(opt-lambda formals body ...)` — *syntax*

Like `lambda`, but `formals` may contain `#:optional` and/or `#:rest` sections: `(req ... #:optional opt ... #:rest rest-var)`, where each `opt` is either a bare `name` (defaults to `(default-object)` if not supplied) or `(name default-expr)` (evaluated only if needed, and only once, at call time). `#:rest rest-var` or a trailing dotted tail both collect any arguments left over.

```scheme
(define greet (opt-lambda (name #:optional (greeting "Hello")) (string-append greeting ", " name)))
(greet "Ada")        ; => "Hello, Ada"
(greet "Ada" "Hi")    ; => "Hi, Ada"

(define f (opt-lambda (a #:optional b #:rest more) (list a b more)))
(f 1)        ; => (1 (srfi-227-default-object) ())  -- b defaulted; check with default-object?, don't rely on the printed form
(f 1 2 3 4)  ; => (1 2 (3 4))
```

#### `(default-object)` → *the default-object marker*

Returns the sentinel value an omitted optional parameter is bound to when no `default-expr` was given for it.

#### `(default-object? obj)` → *boolean*

`#t` iff `obj` is that sentinel — the only reliable way to detect "this optional argument wasn't supplied" when the parameter has no explicit default. The sentinel isn't `#f`, `'()`, or any other ordinary value, so it can't be confused with a legitimately-passed argument.

```scheme
(define f (opt-lambda (a #:optional b) (if (default-object? b) 'no-b b)))
(f 1)    ; => no-b
(f 1 2)  ; => 2
```

#### `(let-optionals rest-list ((var default-expr-or-nothing) ... [. tail-var]) body ...)` — *syntax*
#### `(let-optionals* rest-list ((var default-expr-or-nothing) ... [. tail-var]) body ...)` — *syntax*

Destructure a list (typically a rest-arg list) positionally against `var`s with defaults, the way `opt-lambda`'s `#:optional` section does for a whole lambda. `rest-list` is evaluated once; bindings happen left to right, and a later `default-expr` may reference an earlier `var` — curry doesn't distinguish the stricter `let-optionals` the reference implementation defines (which forbids that); both forms here are the same implementation.

```scheme
(let-optionals (list 1 2) ((a 0) (b 0) (c 10))
  (list a b c))
; => (1 2 10)   -- a and b come from the list, c defaults (list exhausted)
```
