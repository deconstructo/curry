# `(srfi s128 comparators)` — SRFI-128 comparators

```scheme
(import (srfi s128 comparators))
```

[SRFI-128](https://srfi.schemers.org/srfi-128/): a *comparator* bundles a type-test predicate, an equality predicate, and (optionally) an ordering predicate and a hash function into one value — the foundation [`(srfi s113 sets-and-bags)`](s113.md) and [`(srfi s125 hash-tables)`/(srfi s126 hashtables)`](s125-s126.md) are both built on.

## The comparator record

#### `(make-comparator type-test equality ordering hash)` → *comparator*

`type-test` is a predicate (or `#t` for "accept anything"). `equality` is a 2-argument predicate. `ordering` and `hash` are each either a procedure or `#f` — pass `#f` for either if this comparator doesn't support ordering/hashing (calling the corresponding operation later raises, rather than the comparator being simply incomplete).

#### `(comparator? obj)` → *boolean*
#### `(comparator-ordered? cmp)` → *boolean*
#### `(comparator-hashable? cmp)` → *boolean*

#### `(comparator-type-test-predicate cmp)` → *procedure*
#### `(comparator-equality-predicate cmp)` → *procedure*
#### `(comparator-ordering-predicate cmp)` → *procedure*

Raises if `cmp` isn't ordered.

#### `(comparator-hash-function cmp)` → *procedure*

Raises if `cmp` isn't hashable.

#### `(comparator-test-type cmp obj)` → *boolean*

`((comparator-type-test-predicate cmp) obj)`.

#### `(comparator-check-type cmp obj)` → *obj*

Returns `obj` unchanged if it passes `cmp`'s type test; raises otherwise.

#### `(comparator-hash cmp obj)` → *non-negative exact integer*

`((comparator-hash-function cmp) obj)`.

## Chained comparison

#### `(=? cmp obj ...)` → *boolean*
#### `(<? cmp obj ...)` → *boolean*
#### `(>? cmp obj ...)` → *boolean*
#### `(<=? cmp obj ...)` → *boolean*
#### `(>=? cmp obj ...)` → *boolean*

`#t` iff every adjacent pair among `obj ...` (in the order given) satisfies the relation, using `cmp`'s equality (`=?`) or ordering (the other four) predicate. Zero or one object is trivially `#t`. `<?`/`>?`/`<=?`/`>=?` all raise if `cmp` isn't ordered.

```scheme
(<? string-comparator "a" "b" "c")  ; => #t  (a<b and b<c)
(<? string-comparator "a" "c" "b")  ; => #f  (c<b fails)
```

## Basic-type comparators

Ready-made comparators for R7RS's built-in types: `boolean-comparator`, `real-comparator` (alias `number-comparator`), `char-comparator`, `char-ci-comparator` (case-insensitive), `string-comparator`, `string-ci-comparator`, `symbol-comparator`, `eq-comparator` (equality only, not ordered/hashable), `eqv-comparator` (equality + hash, not ordered), `equal-comparator` (equality + hash, not ordered).

## Compound comparators

#### `(pair-comparator car-cmp cdr-cmp)` → *comparator*
#### `(list-comparator elt-cmp)` → *comparator*
#### `(vector-comparator elt-cmp)` → *comparator*

Build a comparator for pairs/lists/vectors out of a comparator for their elements — lexicographic ordering (car first for pairs, element-by-element for lists/vectors, with a shorter list/vector always ordered before a longer one that shares its prefix). **Simplified relative to the full SRFI-128 constructors**, which additionally take custom type-test/car/cdr/null? procedures so non-pair "list-like" structures can be compared too; these three work only on genuine pairs, proper lists, and vectors.

```scheme
((comparator-equality-predicate (list-comparator real-comparator)) '(1 2 3) '(1 2 3))  ; => #t
```

## Default comparator registry

#### `default-comparator` — *comparator*
#### `(make-default-comparator)` → *comparator*

A comparator that accepts any value, ordering across types in the sequence SRFI-128 prescribes: booleans < numbers < chars < strings < symbols < pairs < vectors < anything registered via `comparator-register-default!` < everything else (falls back to `equal-comparator`). `default-comparator` is one fixed instance; `make-default-comparator` returns a fresh one that sees the registry as it stood *at the time it's created* — registering a new comparator afterward doesn't retroactively affect an already-created instance's ordering decisions for types outside the seven built-in ones, only future `make-default-comparator` calls.

#### `(comparator-register-default! cmp)`

Appends `cmp` to the registry consulted by `make-default-comparator`/`default-comparator` for any object none of the seven built-in type-tests accept — tried in registration order, first whose `comparator-test-type` accepts the object wins.

```scheme
(=? default-comparator '(1 2) '(1 2))  ; => #t
(<? default-comparator #t 5)           ; => #t  (booleans order before numbers)
```
