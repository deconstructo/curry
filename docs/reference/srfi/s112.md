# `(srfi s112 environment-inquiry)` — SRFI-112 environment inquiry

```scheme
(import (srfi s112 environment-inquiry))
```

Thin re-export of `(curry posix)`'s six [SRFI-112](https://srfi.schemers.org/srfi-112/) procedures (`implementation-name`, `implementation-version`, `cpu-architecture`, `machine-name`, `os-name`, `os-version`) — see [`../module-posix.md#environment-inquiry-srfi-112`](../module-posix.md#environment-inquiry-srfi-112). Also requires `-DBUILD_MODULE_POSIX=ON` (the default), since `uname(2)`/`gethostname(2)` are syscalls with no Scheme-level equivalent to build on.
