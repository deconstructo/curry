# `(srfi s195 multiple-value-boxes)` — SRFI-195

```scheme
(import (srfi s195 multiple-value-boxes))
```

[SRFI-195](https://srfi.schemers.org/srfi-195/): extends [SRFI-111](s111.md)'s single-value box to hold zero or more values at once, and adds procedures to inspect/update individual slots without unpacking the whole box.

## Shared with SRFI-111

`box`, `box?`, `unbox`, and `set-box!` are the exact same bindings as [`(srfi s111 boxes)`](s111.md) — not a reimplementation. `box` now accepts any number of arguments (including zero), `unbox` returns that many values via `call-with-values`, and `set-box!` requires the new value count to match the box's current arity.

```scheme
(define b (box 1 2 3))
(call-with-values (lambda () (unbox b)) list)  ; => (1 2 3)
(set-box! b 'a 'b 'c)
(call-with-values (lambda () (unbox b)) list)  ; => (a b c)

(define e (box))                                ; a zero-value box
(call-with-values (lambda () (unbox e)) list)   ; => ()
```

Because both libraries share the same underlying `box`/`unbox`/`set-box!`, importing both into one program (as SRFI-195 requires support for) works with no binding conflicts — `(eq? box box)` after importing both is trivially `#t`.

## New procedures

#### `(box-arity b)` → *exact integer*

Number of values `b` currently holds, without unboxing them.

```scheme
(box-arity (box 1 2 3))  ; => 3
(box-arity (box))         ; => 0
```

#### `(unbox-value b i)` → *value*

The `i`-th value in `b` (0-indexed), without unpacking the rest. Raises an error if `i` is negative or `>= (box-arity b)`.

```scheme
(unbox-value (box 'a 'b 'c) 1)  ; => b
```

#### `(set-box-value! b i obj)`

Replaces just the `i`-th value in `b` with `obj`, leaving the others and `b`'s arity unchanged. Raises an error if `i` is negative or `>= (box-arity b)`.

```scheme
(define b (box 1 2 3))
(set-box-value! b 1 'two)
(call-with-values (lambda () (unbox b)) list)  ; => (1 two 3)
```

## Worked example (from the SRFI-195 spec)

A box used as an accumulator pair `(list . count)`, threaded through `for-each` via `call-with-values` (curry's compiler doesn't yet support `let-values`/`let*-values` — see the `s125-s126.md` doc for the same caveat — so `call-with-values` is used directly rather than the spec's own `let-values`-based phrasing):

```scheme
(define rb (box '() 0))
(for-each
 (lambda (e)
   (call-with-values (lambda () (unbox rb))
     (lambda (lis n) (set-box! rb (cons e lis) (+ 1 n)))))
 '(1 2 3 4 5))
(call-with-values (lambda () (unbox rb)) list)  ; => ((5 4 3 2 1) 5)
```
