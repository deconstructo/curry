# `(srfi s98 os-environment-variables)` — SRFI-98

```scheme
(import (srfi s98 os-environment-variables))
```

[SRFI-98](https://srfi.schemers.org/srfi-98/): a thin re-export — both procedures are already native builtins matching SRFI-98/R7RS `(scheme process-context)` exactly, re-exported here only so code using the `(srfi sN name)` naming convention works unchanged.

#### `(get-environment-variable name)` → *string or `#f`*

The value of environment variable `name`, or `#f` if it isn't set.

```scheme
(get-environment-variable "HOME")             ; => "/home/alice"
(get-environment-variable "NOT_SET_ANYWHERE")  ; => #f
```

#### `(get-environment-variables)` → *alist*

Every environment variable as an alist of `(name . value)` pairs, both strings. Order is unspecified (whatever order the underlying `environ`/`envp` array is in).

```scheme
(assoc "HOME" (get-environment-variables))  ; => ("HOME" . "/home/alice")
```
