# `(srfi s1 lists)` — SRFI-1 list library

```scheme
(import (srfi s1 lists))
```

[SRFI-1](https://srfi.schemers.org/srfi-1/): list-processing utilities layered on curry's native list operations.

## Constructors and accessors

Most constructors and accessors are re-exported from `(scheme base)`: `cons`, `car`, `cdr`, `list`, `list*`, `make-list`, `length`, `append`, `reverse`, `list-tail`, `list-ref`, `list-copy`.

#### `(xcons d a)` → *pair*

`(cons a d)` with the arguments swapped — useful when `d` is already in hand and `a` is being computed.

#### `(cons* obj1 obj2 ... objN-1 lst)` → *value*

Like `list`, but the last argument becomes the tail instead of a final element: `(cons* 1 2 '(3 4))` → `(1 2 3 4)`. With one argument, returns it unchanged.

#### `(list-tabulate n f)` → *list*

`(list (f 0) (f 1) ... (f (- n 1)))`.

#### `(circular-list obj ...)` → *circular list*

A genuinely circular list — the last pair's `cdr` points back to the first. Not something to pass to `write`/`display` or anything else without cycle detection: curry's `write`/`display` have no cycle detection at all (a pre-existing core gap, documented in [`(srfi 279)`](s279.md#known-limitations)'s own known limitations) and will hang forever on one.

#### `(iota count)` → *list*
#### `(iota count start)` → *list*
#### `(iota count start step)` → *list*

Return a list of `count` numbers beginning at `start` (default 0) and incrementing by `step` (default 1).

```scheme
(iota 5)           ; => (0 1 2 3 4)
(iota 4 1)         ; => (1 2 3 4)
(iota 5 0 0.5)     ; => (0 0.5 1.0 1.5 2.0)
```

#### `(last-pair lst)` → *pair*

Return the last pair of `lst`.

```scheme
(last-pair '(a b c))  ; => (c)
```

## Named selectors

```scheme
(first   lst) (second lst) (third lst) (fourth lst) (fifth lst)
(sixth   lst) (seventh lst) (eighth lst) (ninth lst) (tenth lst)
```

#### `(take-right lst n)` → *list*
#### `(drop-right lst n)` → *list*

The last `n` elements of `lst`, and `lst` with its last `n` elements removed, respectively. (`take!`/`drop-right!` are also provided as plain aliases — see the note on `!`-suffixed procedures below.)

#### `(split-at lst n)` → *list list* (two values)

`(values (take lst n) (drop lst n))`.

#### `(last lst)` → *value*

The last element of `lst` (as opposed to `last-pair`, which returns the last *pair*).

## Predicates

#### `(any pred lst1 lst2 ...)` → *value*

Returns the first non-`#f` result of `(pred e1 e2 ...)` across corresponding elements, short-circuiting — not just `#t`/`#f`. `#f` if no call returns true, or immediately once any list is exhausted.

#### `(every pred lst1 lst2 ...)` → *value*

Returns the last predicate result if every call returns true; `#f` on the first failure. `#t` for the empty-list case.

#### `(count pred lst1 lst2 ...)` → *integer*

Count of positions where `pred` returns true, across one or more lists in parallel.

#### `(proper-list? x)` / `(dotted-list? x)` / `(circular-list? x)` / `(null-list? x)` / `(not-pair? x)` → *boolean*

Classify a value by list shape. `circular-list?` uses Floyd's tortoise-and-hare cycle detection (safe on an infinite circular list); `proper-list?` delegates to R7RS's own cycle-safe `list?`.

#### `(list= elt=? lst1 lst2 ...)` → *boolean*

`#t` iff every list has the same length and corresponding elements are `elt=?`.

## Filtering

#### `(remove pred lst)` → *list*

Return a list of all elements for which `pred` returns `#f`. Complement of `filter`.

#### `(delete x lst)` → *list*
#### `(delete x lst =?)` → *list*

Remove all elements `equal?` (or `=?`) to `x`. (`delete!` is a plain alias.)

#### `(delete-duplicates lst)` → *list*
#### `(delete-duplicates lst =?)` → *list*

Remove duplicate elements, keeping the first occurrence of each. (`delete-duplicates!` is a plain alias.)

#### `(partition pred lst)` → *list list*

Return two values: elements satisfying `pred`, elements not satisfying `pred`.

```scheme
(define-values (evens odds) (partition even? '(1 2 3 4 5)))
; evens => (2 4), odds => (1 3 5)
```

## Searching

#### `(find pred lst)` → *value or #f*

The first element satisfying `pred`, or `#f`.

#### `(find-tail pred lst)` → *list or #f*

The first sublist whose `car` satisfies `pred`, or `#f`.

#### `(span pred lst)` / `(break pred lst)` → *list list* (two values)

`span` splits at the first element that fails `pred` (`(values (take-while pred lst) (drop-while pred lst))`); `break` splits at the first element that *satisfies* `pred` (the complement).

#### `(list-index pred lst1 lst2 ...)` → *integer or #f*

The index of the first position where `pred` returns true across corresponding elements, or `#f`.

#### `(member x lst)` → *list or #f*
#### `(member x lst =?)` → *list or #f*
#### `(assoc x alist)` → *pair or #f*
#### `(assoc x alist =?)` → *pair or #f*

The optional 3rd-argument equality predicate — standardized in both R7RS and SRFI-1 — is only available through this library: curry's own global `member`/`assoc` (`(scheme base)`) don't accept a 3rd argument at all.

## Folding, unfolding, mapping

#### `(fold kons knil lst1 lst2 ...)` → *value*

Left-to-right fold. `kons` is called as `(kons e1 e2 ... acc)` — the current element(s) **first**, the accumulator **last**. This is the opposite argument order from `fold-left` (accumulator first) — getting this backwards silently gives wrong answers for any non-commutative `kons`: `(fold cons '() '(1 2 3))` is `(3 2 1)`, not the fold-left-shaped `(((() . 1) . 2) . 3)`.

#### `(fold-right kons knil lst1 lst2 ...)` → *value*

Right-to-left fold, same `(kons e1 e2 ... acc)` argument convention as `fold` above (re-exported from `(scheme base)`, which already implements this correctly).

#### `(reduce f ridentity lst)` → *value*

`ridentity` if `lst` is empty; otherwise `(fold f (car lst) (cdr lst))` — the list's own first element seeds the fold, so `f` is never actually called with `ridentity` unless the list is empty.

#### `(reduce-right f ridentity lst)` → *value*

The `fold-right` analogue of `reduce`.

#### `(unfold p f g seed [tail-gen])` → *list*
#### `(unfold-right p f g seed [tail])` → *list*

Build a list by repeatedly testing `(p seed)`; while false, cons `(f seed)` and recurse on `(g seed)`. `unfold` builds left-to-right (stops via `tail-gen seed`, default `'()`); `unfold-right` builds right-to-left (starts from an optional `tail` accumulator, default `'()`).

#### `(pair-for-each f lst)` → *unspecified*

Like `for-each`, but `f` receives each successive **pair** (sublist) of `lst`, not each element.

#### `(append-map f lst1 lst2 ...)` → *list*

Map `f` over the list(s) and append the results. Equivalent to `(apply append (map f lst1 lst2 ...))`. (`append-map!`/`map!` are plain aliases.)

#### `(filter-map f lst1 lst2 ...)` → *list*

Map `f` and keep non-`#f` results.

#### `(flat-map f lst)` → *list*

Alias for `append-map`.

## Sublists

#### `(take lst n)` → *list*

Return the first `n` elements of `lst`.

#### `(drop lst n)` → *list*

Return `lst` with the first `n` elements removed.

#### `(take-while pred lst)` → *list*

Return the longest prefix of `lst` whose elements all satisfy `pred`.

#### `(drop-while pred lst)` → *list*

Drop elements from the front while `pred` is true; return the remainder.

## Append / concatenate / reverse

#### `(concatenate lists)` → *list*

`(apply append lists)`. (`concatenate!` is a plain alias.)

#### `(append! lst ...)` → *list*

Alias for `append`.

#### `(append-reverse rev-head tail)` → *list*

`(append (reverse rev-head) tail)`, without actually reversing an intermediate list.

#### `(reverse! lst)` → *list*

Alias for `reverse`.

## Zip / unzip

#### `(zip lst1 lst2 ...)` → *list*

`(map list lst1 lst2 ...)`.

#### `(unzip1 lst)` → *list*
#### `(unzip2 lst)` → *list list* (two values)
#### `(unzip3 lst)` / `(unzip4 lst)` / `(unzip5 lst)` → *N values*

Inverse of `zip`: `unzipN` splits a list of N-tuples into N parallel lists.

## Association lists

#### `(alist-cons key val alist)` → *alist*

`(cons (cons key val) alist)`.

#### `(alist-copy alist)` → *alist*

A shallow copy — a fresh list of fresh pairs, so mutating the copy's pairs doesn't affect the original.

#### `(del-assq key alist)` / `(del-assv key alist)` / `(del-assoc key alist)` → *alist*

Remove every entry whose key is `eq?`/`eqv?`/`equal?` to `key`. (`del-assq!`/`del-assv!`/`del-assoc!` are plain aliases.)

## Lists as sets

Every set procedure takes the element-equality predicate as its own first argument (there is no default, unlike `member`/`delete`/`delete-duplicates` above, which all default to `equal?`).

#### `(lset<= =? lst1 lst2 ...)` → *boolean*
#### `(lset= =? lst1 lst2 ...)` → *boolean*

Subset and set-equality tests.

#### `(lset-adjoin =? lst elt ...)` → *list*

`lst` with each `elt` consed on unless it's already present (by `=?`).

#### `(lset-union =? lst ...)` / `(lset-intersection =? lst1 lst ...)` / `(lset-difference =? lst1 lst ...)` / `(lset-xor =? lst ...)` → *list*

Set union, intersection, difference, and symmetric difference. (`!`-suffixed variants are plain aliases — see the note below.)

## A note on `!`-suffixed procedures

SRFI-1 permits (but doesn't require) `!`-suffixed procedures to imperatively splice/mutate their argument list rather than allocate fresh structure. curry implements every `!` variant in this library (`take!`, `drop-right!`, `delete!`, `delete-duplicates!`, `append-map!`, `map!`, `split-at!`, `concatenate!`, `append-reverse!`, `lset-union!`/`-intersection!`/`-difference!`/`-xor!`, `del-assq!`/`-assv!`/`-assoc!`) as a plain alias for the non-destructive version — spec-conformant, and avoids introducing shared-structure mutation hazards under curry's GC'd, immutable-by-convention list-processing style for no real benefit.
